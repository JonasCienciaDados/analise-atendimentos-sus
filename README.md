# 📊 Análise de Atendimentos e Tempo de Espera — SUS/SP 2023

Projeto de análise de dados com foco no sistema ambulatorial do SUS no estado de São Paulo.
Desenvolvido como parte do meu portfólio de transição para Análise de Dados.

## 🎯 Objetivo
Identificar padrões de tempo de espera e taxa de realização de atendimentos por especialidade
e região, gerando insights acionáveis para gestão de saúde.

## 🔍 Perguntas respondidas
- Quais especialidades têm maior tempo de espera?
- Existe diferença significativa entre regiões do estado?
- Quais especialidades têm maior taxa de não comparecimento?

## 💡 Principais insights
| Achado | Impacto |
|---|---|
| Dermatologia e Oftalmologia: 33 dias de espera | Maior gargalo do sistema |
| Oftalmologia: apenas 72,6% de comparecimento | 1 em cada 4 consultas desperdiçadas |
| Clínica Médica: 26% de todos os atendimentos | Porta de entrada sobrecarregada |
| Interior tem menor espera (28 dias) | Boas práticas replicáveis |
